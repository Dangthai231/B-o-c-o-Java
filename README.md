## Backend environment variables

Before starting the backend, supply `SPRING_DATASOURCE_PASSWORD` and `JWT_SECRET` in the IntelliJ run configuration environment. Use your existing local values; do not commit them. The published configuration has no embedded database password or JWT signing secret.
